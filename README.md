# Язык моря в британской маринистической литературе

Проект, анализирующий различными методами язык моря в британской маринистической литературе.

Структура репозитория:
* В папке literature приведена часть используемой литературы (которую разрешено выкладывать в открытый доступ)
* В файле table.csv содержится список всех используемых книг
* В тетрадке project.ipynb содержится код и результаты работы

Также результаты можно увидеть по ссылке: https://elenatutubalina.github.io/language_of_the_sea/
